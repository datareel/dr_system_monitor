# DRSM guides for AI assistants

Task guides for GitHub Copilot, Gemini, Claude and the admins who use
them. Read `AGENTS.md` (in the top folder of the source, and copied
here) first: it has the layout, the report format and the rules.

| Guide | Use it to |
| --- | --- |
| [AGENTS.md](AGENTS.md) | Learn the layout, report format, coding rules and tests |
| [maintain-a-site.md](maintain-a-site.md) | Add or remove hosts, change thresholds, sites, links, alerts, cron, upgrade an install, find why a host is red |
| [write-a-plugin.md](write-a-plugin.md) | Add a check as a plugin, local or for the DRSM release |
| [change-the-dashboard.md](change-the-dashboard.md) | Change or add a PHP page, menu items, other script reports, styles |
| [llms-full.txt](llms-full.txt) | All of the above in one file, to paste into a chat |

The full references are `PLUGINS.md` and the HTML docs in `docs/`.
